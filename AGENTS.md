# Agent Configurations

This repository contains personal configuration files for coding assistants and
agents.

## Repository Guidelines

- Keep `codex/AGENTS.md` and `claude/CLAUDE.md` aligned unless a difference is
  explicitly requested or required by the respective tool.
- Put Codex-specific configuration under `codex/` and Claude-specific
  configuration under `claude/`.
- Preserve the corresponding structure and conventions when adding agents or
  skills for both tools.
- Treat files in this repository as source configurations.  They are copied to
  their installation locations manually; there is no installation mechanism.
- Validate modified TOML and JSON files and check Markdown files for obvious
  formatting problems.
